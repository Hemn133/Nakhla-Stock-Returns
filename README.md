# Nakhla

Shisha shop system: products with units, wasl (receipts) in USD, credit customers
with installments, and a combined customer statement. Central Kurdish, right-to-left.

    nakhla/
    ├── backend/    Node.js + Express + PostgreSQL     (see backend/README.md)
    └── client/     React + Vite + Tailwind CSS        (see client/README.md)

Start order: PostgreSQL -> backend (`npm run dev`) -> client (`npm run dev`).

**Upgrading an existing database? Read backend/README.md, section B, first.**
